# 討論紀錄：先討論、後生成

> 作業要求用「先討論、後生成」的方式建 Wiki。這頁記錄**動手 ingest 之前**，我和 AI（Claude）討論出來的決定。
> 日期：2026-11-23（晚上），對話在 Claude 進行。

## 第 1 輪：選主題

- AI 提了三個方向：Mamba / SSM 入門、虛擬試戴技術、連通元件標記。
- 我給了上週作業的網站（`mamba-video-notes`），問會不會和 Mamba 主題重複。
- AI 看過後指出：上週的網站本身就很像 LLM Wiki（有 `CLAUDE.md` 規則、固定格式、待確認標記），選 Mamba 會變成在同一個知識庫上再做一次。
- **決定：換主題，做「虛擬試戴背後的技術」。** 理由：和上週完全不重疊，「先討論、後生成」的過程是新的，而且調研結果可以直接用在期末專案（穿戴甲品牌 AI 小幫手）。

## 第 2 輪：要讀哪些資料

AI 依照試戴流程的每一步各挑一篇（6 篇）：

| 流程步驟 | 資料 |
|---|---|
| 找到手 | MediaPipe Hands（2020） |
| 找到指甲 | Nail Polish Try-On（ModiFace, 2019） |
| 生成的基礎 | Latent Diffusion Models（2021/2022） |
| 控制形狀 | ControlNet（2023） |
| 參考款式圖 | IP-Adapter（2023） |
| 完整試戴系統 | IDM-VTON（2024，做衣服，當作完整案例） |

AI 問了兩件事：範圍要不要包含一般服裝試戴？清單要不要換？

## 第 3 輪：我的回答 → 定出核心問題

我的回覆重點：

1. 期末專案還沒決定用「直接把指甲圖貼到手上」還是「用 diffusion 生成」，**不確定兩者效果差在哪**。
2. **可能需要考慮指甲曲面和光影渲染**。
3. 要推到 GitHub，最後做成教學 HTML 簡報。
4. 提供了 5 張自己品牌的穿戴甲作品照（櫻桃立體、星星、蝴蝶結珍珠、珍珠光澤、蕾絲）。

**由討論得出的決定：**

- **核心問題**：「2D 貼圖」和「diffusion 生成」差在哪？各自怎麼處理指甲曲面與光影？→ 寫進 `CLAUDE.md` 第 1 節，每篇 source 頁都要有「關於曲面與光影」段落。
- **範圍**：以指甲為主；IDM-VTON 只當「完整生成式試戴系統長怎樣」的案例，不展開服裝試戴的其他論文。
- **清單**：維持 6 篇。
- **簡報讀者**：不懂電腦視覺的人（例如我的客人或同學）。用我的作品照片當例子。
- **格式**：沿用上週 `CLAUDE.md` 的誠信規則與檢查腳本；Wiki 改用 Markdown（`index.md` + `log.md` + 三層結構），比上週的 HTML 網站更接近 LLM Wiki 的做法。
